# Aghanims Receipt Generator v3 — CasaOS / Docker Ready

Self-hosted receipt generator for Aghanims Phones & Gadgets.

## v3 changes

- Centralized receipt history stored in SQLite on the server using Node.js 22 built-in SQLite.
- History is shared by every phone/PC that opens the same server URL.
- Persistent database at `/app/data/receipts.db` in Docker.
- Create/update receipts, search/filter history, reopen, regenerate PDF, and delete.
- Receipt numbers such as `AGP-20260919-001` are generated by the browser based on the date/history.
- Product fetching is restricted to `aghanimsphones.in`.
- A4 PDF / print receipt layout based on the supplied reference.
- JSON export is retained as a convenient backup.

## CasaOS — easiest deployment

1. Copy/extract this folder onto your CasaOS server.
2. Open CasaOS Terminal (or SSH) in this folder.
3. Run:

```bash
docker compose up -d --build
```

4. Open:

```text
http://YOUR-SERVER-IP:9009
```

The database is stored in `./data/receipts.db` on the host because `./data:/app/data` is mounted.

### CasaOS Custom App

If you prefer CasaOS UI, use Docker Compose / Custom Install and paste the contents of `docker-compose.yml`. Build the image from this folder, or build it first with:

```bash
docker compose build
```

### Reverse proxy / domain

For a domain such as `receipt.aghanimsphones.in`, point the DNS record to your public IP and reverse-proxy HTTPS traffic to port `9009`. Do not expose port 9009 directly to the internet unless your network/firewall is configured appropriately.

## Backup

Back up this file regularly:

```text
./data/receipts.db
```

You can also use the app's **Export history** button for a JSON backup.

## Windows local testing

Install Node.js 22+ and double-click `start.bat`, then open `http://localhost:3000`.

## API

- `GET /api/health`
- `GET /api/receipts`
- `POST /api/receipts`
- `DELETE /api/receipts/:id`
- `DELETE /api/receipts`
- `GET /api/product?url=...`
